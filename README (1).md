# LD Workplace

লার্নিং অ্যান্ড ডেভেলপমেন্ট টিমের ট্রেনিং ট্র্যাকার। ওয়েবসাইট GitHub Pages-এ হোস্ট হয়, আর সব ডাটা Google Sheets-এ জমা হয়।

## ফাইল

| ফাইল | কাজ |
| --- | --- |
| `index.html` | পুরো ওয়েবসাইট। এটি GitHub-এ আপলোড করবেন। |
| `Code.gs` | Google Sheets-এর সাথে যোগাযোগের কোড। এটি GitHub-এ লাগবে না, Apps Script-এ পেস্ট করবেন। |

## প্রথমবার সেটআপ

1. Google Sheet-এর মেনু থেকে **Extensions > Apps Script** খুলুন এবং `Code.gs`-এর পুরো লেখা পেস্ট করে Save করুন।
2. `setup` বেছে **Run** চাপুন। অনুমতি চাইলে Allow দিন। এতে সব ট্যাব ও কলাম তৈরি হবে।
3. পাসওয়ার্ড সেট করতে কোডের ওপরে `SHARED_PASSWORD = '';` লাইনে কমন পাসওয়ার্ড লিখুন (অথবা `USERS_TO_CREATE`-এ প্রত্যেকের আলাদা পাসওয়ার্ড দিন)। তারপর Save করে `createUsers` Run করুন।
4. এরপর পাসওয়ার্ড আবার মুছে খালি (`''`) করে Save করুন।
5. **Deploy > New deployment > Web app** বেছে নিন। Execute as **Me**, Who has access **Anyone**, তারপর Deploy চাপুন।
6. `/exec` লিংকটি `index.html`-এর `API_URL: ''`-এর ভেতরে বসান (এই ফাইলে ইতিমধ্যে বসানো আছে)।
7. GitHub রিপোজিটরিতে `index.html` আপলোড করে **Settings > Pages** থেকে `main` ব্রাঞ্চ ও `/ (root)` বেছে Save করুন।

## আপডেট করার নিয়ম (নতুন ফিচার এলে)

1. `Code.gs`-এর নতুন লেখা Apps Script-এ পুরনো কোডের জায়গায় পেস্ট করে Save করুন।
2. `setup` আবার **Run** করুন। এতে নতুন ট্যাব (`Settings`) ও নতুন কলাম (`Shift`, `Trainer`, `Reviewer`) যোগ হবে। আগের ডাটা মুছবে না।
3. পাসওয়ার্ড আবার সেট করতে চাইলে ধাপ ৩-৪ করুন। না চাইলে বাদ দিন।
4. **Deploy > Manage deployments**-এ পেন্সিল আইকন চেপে **Version: New version** বেছে **Deploy** করুন। লিংক একই থাকবে।
5. নতুন `index.html` GitHub-এ আপলোড করুন (পুরনোটার ওপর Replace)।

## কোন পেজ কী করে

- **Dashboard**: এই মাসের সেশন, শিফট অনুযায়ী গ্রুপ সেশন, কল রিভিউ, প্রত্যেক মেম্বারের কাজ ও চলমান ব্যাচের অগ্রগতি।
- **Team board**: ৪ জন মেম্বার পাশাপাশি। আজ, শেষ ৭ দিন বা এই মাসে কে কোন শিফটে (Morning LD বা Evening LD) কী সেশন নিল এবং কয়টা কল রিভিউ করল।
- **Batches**: ব্যাচের তারিখ, স্ট্যাটাস, কয়টা গ্রুপ ও 1-to-1 সেশন হবে (যেকোনো সময় এডিট করা যায়)।
- **Agents**: ব্যাচ অনুযায়ী এজেন্ট ও ট্রেনিং ফিডব্যাক।
- **Session log**: তারিখ, শিফট, ব্যাচ, কে নিল, বিষয় ও কী কভার হলো। "Save and add another" দিয়ে পরপর কয়েকটা এন্ট্রি দ্রুত দেওয়া যায়।
- **Training materials**: ডকুমেন্ট, স্লাইড, ভিডিওর লিংক।
- **Call review**: লাইভ বা রেকর্ডেড কল, তারিখ, মিনিট, ডিসপোজিশন ও রিমার্কস (কপি-পেস্ট করা যায়)।
- **Performance**: সেরা পারফর্মার, দুর্বল এজেন্ট ও আন্ডার পারফর্মার, সাথে ট্রেনিং প্ল্যান।
- **QA handover**: ১ মাস শেষে QA-তে কীভাবে হস্তান্তর করা হলো।
- **Monthly report**: মাসের মোট সেশন, শিফট ও মেম্বার অনুযায়ী হিসাব, বিষয় ও ডিসপোজিশন। "Copy summary" দিয়ে স্লাইডের টেক্সট নেওয়া যায়, আর "Print or save as PDF" দিয়ে PDF করা যায়।
- **Options**: ড্রপডাউনের তালিকা নিজে বাড়ানো বা কমানো যায়, যেমন নতুন শিফট (Night LD), নতুন টিম মেম্বার, নতুন ট্রেনিং টপিক বা ডিসপোজিশন। বদলগুলো `Settings` ট্যাবে জমা হয়।

## আগে ট্রাই করতে চাইলে (ডেমো মোড)

`index.html`-এ `API_URL: ''` খালি করলে ডেমো মোড চালু হয়। ইউজারনেম `demo`, পাসওয়ার্ড `demo`। ডাটা শুধু ওই ব্রাউজারেই থাকে।

## নিরাপত্তা ও জানার বিষয়

- পাসওয়ার্ড কোডে বা GitHub-এ রাখবেন না। ব্যবহারের পর মুছে দিন।
- লগইন সেশন ৬ ঘণ্টা চলে। পরপর ৫ বার ভুল পাসওয়ার্ড দিলে ১৫ মিনিটের জন্য ওই ইউজার আটকে যায়।
- ফ্রি GitHub প্ল্যানে Pages সাধারণত পাবলিক রিপোজিটরি থেকে চলে, তাই রিপোজিটরিতে কোনো গোপন তথ্য রাখবেন না।
- Google Sheet-এ সরাসরি ডাটা এডিট করা যায়, কিন্তু প্রথম সারির হেডার ও `ID` কলাম বদলাবেন না।
